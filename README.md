# Scott Williams Portfolio

Next.js (App Router) portfolio site for Scott Williams — Senior Software Engineer specializing in mobile and web development.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Personalized copy and links live in `data/`. The original static HTML theme is archived under `_legacy/` for reference.
